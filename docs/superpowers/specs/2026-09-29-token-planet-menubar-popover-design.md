# Token Planet 메뉴바 행성 팝오버 설계

**작성일:** 2026-09-29

**상태:** 대화 중 화면·동작 방향 승인, 문서 검토 대기

## 목표와 범위

macOS 메뉴바의 행성 아이콘을 클릭하면 아이콘 바로 아래에 작은 행성 팝오버를 표시한다. 팝오버의 `행성·그룹 자세히 보기` 버튼은 현재의 상세 화면을 일반 창으로 열고, 상세 화면의 `행성으로 돌아가기` 버튼은 같은 팝오버로 복귀한다.

첨부 이미지는 메뉴바 아래에 붙는 패널 형태와 정보의 시각적 위계를 보여 주는 참고 자료다. 화분, 물주기, 상점, 도감, 예시 수치와 밝은 회색 팔레트는 Token Planet의 기능 요구사항이 아니다. 기존의 어두운 픽셀 행성 스타일과 현재 데이터의 의미를 유지한다.

이번 범위는 데스크톱 창 표시 방식과 기본 화면의 정보 배치다. 행성 성장 공식, 사용량 수집, 공유 API, 상점 및 저장 형식은 바꾸지 않는다.

## 화면 모드와 전환

| 상태 | 보이는 화면 | 진입 | 이탈 |
| --- | --- | --- | --- |
| 팝오버 | 아이콘 아래의 작은 행성 요약 | 메뉴바 아이콘 클릭, 상세의 `행성으로 돌아가기` | 자세히 보기, 아이콘 재클릭, 바깥 클릭, `Esc` |
| 상세 | 기존 `내 행성`·`그룹` 화면을 담은 중앙 창 | 팝오버의 `행성·그룹 자세히 보기` | `행성으로 돌아가기`, 창 닫기 |
| 숨김 | 창을 숨기고 메뉴바 아이콘 유지 | 팝오버 닫기, 상세 창 닫기 | 아이콘 클릭 |
| 프로필 설정 | 현재 프로필 생성 화면을 담은 일반 창 | 프로필이 없는 최초 실행 | 프로필 저장 후 행성 화면 |

- 팝오버가 열린 상태에서 아이콘을 다시 클릭하면 숨긴다. 숨긴 뒤 클릭하면 현재 상태와 관계없이 팝오버를 연다.
- 상세 화면이 열린 상태에서 아이콘을 클릭하면 팝오버로 전환한다. 상세 창을 두 개 만들지 않는다.
- 팝오버의 바깥을 클릭하거나 `Esc`를 누르면 숨긴다. 상세 창에서 포커스가 빠졌다는 이유만으로 창을 숨기지 않는다.
- 상세를 열 때마다 기존 동작처럼 `내 행성` 탭을 먼저 선택한다. 상세에서 그룹을 보다가 돌아가도 팝오버에는 내 행성 요약을 보여 준다.
- 창을 닫아도 앱은 종료하지 않고 메뉴바 아이콘에서 다시 열 수 있다. `종료` 메뉴만 앱을 종료한다.
- 프로필이 없으면 작은 팝오버 대신 현재 프로필 설정 창을 유지한다. 프로필을 저장한 뒤에는 팝오버를 표시한다.
- 프로필이 있는 상태에서 앱을 시작하면 첫 화면도 팝오버로 표시한다.

## 팝오버 내용과 시각 디자인

팝오버는 기존 기본 화면의 데이터를 압축해서 보여 준다. 약 390~420px 너비를 목표로 하되, 사용 가능한 화면의 너비와 높이를 넘지 않는다. 메뉴바 바로 아래에 간격을 두고 놓으며, 화면 모서리에서는 패널이 잘리지 않도록 수평 위치를 보정한다. 화면 높이가 모자라면 본문 영역만 세로 스크롤한다.

1. **상단:** Token Planet 이름과 새로고침 동작. 갱신 중에는 버튼 상태가 드러난다.
2. **행성 영역:** 현재 행성 장면을 가장 크게 보여 주고, 닉네임과 현재 시대를 붙인다.
3. **성장 요약:** 이번 행성 토큰과 다음 시대 진행도. 최종 시대에서는 현재의 최종 시대 문구를 표시한다.
4. **주 동작:** `행성·그룹 자세히 보기` 버튼을 주요 수치 바로 다음의 찾기 쉬운 위치에 둔다. 긴 관리 기능은 기존 상세 화면에 둔다.
5. **보조 정보:** 전체 사용량, Codex·Claude Code 수집 상태, 동기화 상태. 확인되지 않은 값과 `일부 기록 확인 중`을 실제 0과 구분한다.

현재의 밤색 배경, 민트·물색·금색 포인트, 픽셀 행성과 글자 크기 기준을 이어간다. 팝오버 외곽은 둥근 모서리와 분리된 그림자로 화면 위에 떠 있는 느낌을 주되, 내용의 픽셀 표현과 대비를 해치지 않는다. 주요 버튼은 키보드 초점이 보이고 최소 44px 높이를 유지한다.

## 창 구현 경계

우선 `main` 웹뷰 창 하나를 팝오버와 상세 모드로 전환한다. React의 현재 `detail` 상태와 스냅샷을 재사용하면 두 웹뷰 사이의 상태 복제나 중복 수집 구독이 필요 없다. 네이티브 창 모드 변경은 한 경로에서 크기·위치·장식·표시 상태를 함께 적용한다. 변경에 실패하면 React 화면만 먼저 전환하지 않고 현재 화면을 유지하며 사용자에게 오류를 표시한다.

- `src-tauri/src/platform/tray.rs`: 아이콘 클릭으로 팝오버 열기·숨기기, 아이콘 영역 확인, 복귀 위치 계산을 맡는다.
- `src-tauri/src/lib.rs`: 팝오버와 상세 창 모드 전환, 프로필 설정 예외, 포커스 이탈에 따른 팝오버 숨김을 맡는다. 기존 닫기 시 숨김 동작은 유지한다.
- `src/App.tsx`: 팝오버에 맞는 요약 구조와 버튼을 표시하고, 현재 상세 탭과 데이터 조회 흐름을 유지한다.
- `src/App.css`: 팝오버 전용 크기·스크롤·외곽 디자인을 정의한다. 상세 화면의 내용은 기존 배치를 유지한다.

메뉴바 아이콘의 현재 영역을 전환할 때마다 다시 읽고, 물리 좌표와 화면 배율을 반영해 팝오버를 배치한다. 다중 모니터, 메뉴바 자동 숨김, 화면 가장자리에서 실제 위치를 확인한다. 아이콘 영역을 얻지 못하면 화면 안에 온전히 보이는 위치로 표시하는 대체 경로를 둔다. Windows에서는 트레이 클릭과 상세 복귀가 계속 동작하도록 하되, 작업 표시줄 위치에 따른 배치는 해당 운영체제에서 따로 검증한다.

## 오류와 상태

- 사용량 조회 실패, 수집 불완전, 동기화 오류는 팝오버에서 상태를 숨기지 않는다. 자세한 설명과 설정은 상세 화면에서 확인한다.
- 팝오버를 숨겨도 백그라운드 수집과 동기화는 계속된다. 다시 열면 최신 스냅샷을 표시한다.
- 상세로 전환하거나 돌아올 때 행성을 초기화하거나 수치를 재계산하지 않는다.
- 창 전환 실패 시 사용자가 보던 화면을 유지하고 재시도할 수 있게 한다.

## 검증 기준

1. macOS에서 메뉴바 아이콘 클릭 시 팝오버가 아이콘 아래에 나타나며 제목 표시줄이 없고 화면 밖으로 나가지 않는다.
2. 아이콘 재클릭, 바깥 클릭, `Esc`로 팝오버가 숨겨지고 다시 열 수 있다. 상세 창은 바깥 클릭만으로 사라지지 않는다.
3. 자세히 보기와 돌아가기를 반복해도 `내 행성`·`그룹` 상세 기능, 토큰 수치, 진행도, 수집·동기화 상태가 유지된다.
4. 작은 화면과 다중 모니터에서 내용이 겹치거나 잘리지 않으며, 필요한 경우 팝오버 본문을 스크롤할 수 있다.
5. 최초 프로필 설정, 오류 상태, 창 닫기, 메뉴바의 `종료`가 각각 의도한 화면 상태로 이어진다.
6. React 화면 전환 테스트와 Tauri 위치·상태 전환의 단위 검증 후, macOS 실제 메뉴바 클릭과 포커스 동작을 수동으로 확인한다. Windows 트레이 동작은 Windows 환경에서 별도로 확인한다.
