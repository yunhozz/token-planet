# Token Planet 아바타 상호작용·상점 확장 설계

**작성일:** 2026-09-29
**상태:** 사용자 문서 검토 대기

## 목표와 범위

행성의 아바타가 덜 반복적으로 움직이고, 행성이나 아바타를 누르면 현재 상태에 맞는 짧은 대사를 말한다. 꾸미기 상점에서는 더 많은 장식을 고르고 여러 부위에 함께 장착할 수 있으며, 새 구매 가격은 현재보다 높인다.

이번 변경은 기존 픽셀 행성의 시각 스타일을 유지한다. 장식·움직임·대사는 성장 점수, 토큰 집계, 행성 초기화, 순위에 영향을 주지 않는다. 대사 생성을 위해 외부 AI나 원본 사용 기록을 호출하지 않는다.

## 접근 방식과 선택

1. **추천: 기존 상품의 새 가격 SKU와 신규 장식을 함께 출시한다.** 기존 SKU는 판매를 종료하되 보유·장착·구매 당시 가격을 보존한다. 같은 외형의 새 SKU를 구매 목록에 올리고 신규 슬롯을 하나 추가한다. 서버가 이미 등록된 SKU의 가격 변경을 금지하고 게스트 구매 가져오기에서 등록 가격을 확인하므로 현재 계약과 맞는다.
2. 기존 SKU의 가격을 수정하는 방식은 가격 불변 트리거, 카탈로그 수정 번호, 구매 재시도, 게스트 구매 가져오기 정책을 바꿔야 한다. 이미 구매한 금액은 원장에 남지만 같은 SKU의 과거·현재 판매 가격이 달라진다.
3. 기존 가격을 유지하고 신규 장식만 비싸게 판매하는 방식은 간단하지만 기존 상품도 인상하려는 요구를 충족하지 못한다.

## 아바타 움직임

- 지금처럼 행성 표면의 검증된 `WALK_POINTS`만 사용한다. 한 번 움직일 때 방향과 1~5칸 떨어진 목적지를 고르고, 인접 지점을 순서대로 지나간다. 끝 지점에서는 경로를 다시 고르며 순간 이동하지 않는다.
- 이동 후 쉬는 시간은 약 1.5~5초, 한 칸의 이동 시간은 약 0.3~0.55초 범위에서 고른다. 같은 두 지점을 연속해서 왕복하는 경로는 한 번 다시 추첨한다. 눈 깜빡임과 짧은 시선 전환을 섞되 계속 움직여 산만해지지 않게 한다.
- 걷는 도중 말풍선을 열면 현재 이동을 멈추고 대사를 보여준다. 말풍선이 닫히면 새 쉬는 시간 후 걷기를 재개한다. 클릭이나 재렌더 때문에 아바타 위치가 초기 위치로 튀지 않는다.
- 작은 그룹 행성 카드는 정지 상태를 유지한다. 화면 밖, 숨겨진 창, 운영체제의 `동작 줄이기` 설정에서는 반복 이동·깜빡임을 멈춘다. 움직임의 난수는 장면 표현에만 사용하며 저장 데이터·동기화 데이터에 넣지 않는다.

## 클릭과 말풍선

- 내 행성은 팝오버와 상세 화면에서, 그룹 행성은 선택해 크게 보는 장면에서 상호작용한다. 작은 그룹 행성 카드는 기존의 행성 선택 버튼으로 남는다.
- 아바타를 누르면 아바타 대사 후보를, 행성의 나머지 영역을 누르면 행성 상태 대사 후보를 고른다. 아바타 클릭은 행성 클릭으로 중복 처리하지 않는다. 한 번에 말풍선 하나만 보이며 연속 클릭은 내용과 닫힘 시간을 갱신한다. 마지막 대사를 바로 반복하지 않는다.
- 대사는 사전에 작성한 짧은 한국어 문장이다. 우선순위는 `새 오브젝트 확인` → `수집 상태 불완전` → `다음 시대에 근접` → `현재 시대` → `기본 대사`다. 예: “새로운 나무가 자랐어!”, “아직 기록을 확인하는 중이야.”, “다음 시대가 가까워!”, “오늘은 어디를 둘러볼까?” 정확한 새 오브젝트가 없다면 새로 생겼다고 말하지 않는다. 다른 멤버의 장면에는 공개된 시대·진행도·장식만 사용하고 개인별 기록 상태나 토큰 수치를 대사에 포함하지 않는다.
- 새 오브젝트 대사는 같은 행성 주기에서 화면이 이미 알고 있던 오브젝트와 새 스냅샷을 비교했을 때만 사용한다. 앱을 처음 열 때 존재하던 오브젝트에 생성 시각을 추정해 붙이지 않는다. 그룹 행성은 새 오브젝트 여부를 추정하지 않는다.
- 말풍선은 아바타 위에 붙이고 약 4초 후 사라진다. 장면 경계에서는 위치를 조정해 잘리지 않게 한다. 클릭과 키보드 Enter/Space 모두 지원하고, 각각의 상호작용 대상에 이름과 포커스 표시를 둔다. 대사 변경은 접근성 상태 텍스트로 읽을 수 있게 한다. `동작 줄이기`에서는 등장 애니메이션 없이 바로 표시한다.

## 상점 구성과 가격

지갑 단위는 현재처럼 행성 초기화 때 적립되는 확인 토큰이다. 아래 금액은 이번 출시의 고정 판매 가격이며, 임의로 잔액을 지급하거나 성장 공식을 바꾸지 않는다.

| 슬롯 | 새로 판매할 장식 | 가격 |
| --- | --- | ---: |
| 하늘 | 별무리, 오로라 | 500,000 / 2,000,000 |
| 고리 | 얇은 고리, 이중 고리 | 500,000 / 2,000,000 |
| 지표 | 깃발, 수정탑 | 500,000 / 2,000,000 |
| 하늘 | 유성우 | 1,000,000 |
| 고리 | 작은 위성들 | 3,000,000 |
| 지표 | 꽃 정원, 천문대 | 1,000,000 / 5,000,000 |
| 앞마당 **신규 슬롯** | 연못, 등불, 탐사 로버, 온실 | 750,000 / 1,500,000 / 3,000,000 / 5,000,000 |

- 기존 세 슬롯과 앞마당 슬롯에 각각 하나씩 장착할 수 있어 최대 네 장식이 함께 보인다. 앞마당은 기존 지표 장식과 분리된 영역에 배치한다. 상점·보관함은 슬롯 및 상품 목록을 데이터로 렌더링하며 상품 수를 화면 코드의 고정 개수로 가정하지 않는다.
- 기존 6개 SKU의 100,000·500,000토큰 가격과 구매 원장은 그대로 둔다. 이 SKU는 신규 판매만 중단한다. 동일 외형의 새 SKU 6개를 위 가격으로 등록하고, 이미 구형 SKU를 보유한 사람은 새 외형을 다시 살 필요 없이 기존 장식을 계속 장착한다. 구매 목록은 동일 외형을 중복 상품처럼 표시하지 않으며, 서버 구매 경로도 대응하는 구형 SKU 보유자에게 동일 외형의 새 SKU를 중복 판매하지 않는다. 구형 SKU의 게스트 구매를 새 가격으로 재계산하지 않는다.
- 새로운 장식 8개는 자체 SKU·고정 가격·슬롯을 가진다. 모든 상품은 영구 보유하고, 초기화하면 현재 장착만 해제한다. 미리보기, 가격과 구매 후 잔액 확인, 온라인 구매 확정, 오프라인 게스트 구매 및 첫 로그인 가져오기는 기존 규칙을 따른다.
- 앞마당 장식과 지표 장식, 성장 오브젝트, 아바타, 말풍선이 서로 주요 형태를 가리지 않도록 배치한다. 그룹에는 장착된 외형만 공유하고 가격·잔액·보유 목록은 공개하지 않는다.

## 구현 경계와 배포

| 영역 | 변경 |
| --- | --- |
| React 장면 | 경로 선택과 말풍선 상태, 클릭·키보드 대상, 새 장식 그림과 슬롯별 배치 |
| React 상점 | 지원 슬롯·SKU, 구형·신형 동일 외형 표시, 확장된 상품 목록과 미리보기 |
| Rust·SQLite | 게스트 카탈로그, 구형 SKU 보존과 신규 SKU 가격, 동일 외형 중복 구매 방지 |
| Supabase | 추가 migration으로 새 슬롯·상품 등록, 구형 SKU 판매 중단, 동일 외형 중복 구매 방지 |

서버 카탈로그와 구매 규칙을 먼저 배포하고 그다음 앱을 배포한다. 구버전 앱은 모르는 SKU와 슬롯을 그리거나 구매하지 않는다. 새 앱은 구형 장식의 구매·장착 기록을 읽을 수 있다. 구매 요청 재시도와 첫 로그인 게스트 구매 가져오기는 이전 SKU 가격으로도 성공해야 한다. 호스팅 Supabase의 설치·인증과 macOS·Windows 실기 출시 점검은 기존 출시 체크리스트의 선행 조건으로 남는다.

## 검증 기준

1. 여러 번 걷는 동안 목적지·거리·속도·휴식이 달라지고 모든 이동은 인접한 표면 지점을 통과한다. 숨김·화면 밖·동작 줄이기에서 반복 움직임이 멈춘다.
2. 행성과 아바타의 클릭·키보드 입력이 각각 한 개의 짧은 대사를 보여준다. 말풍선은 좁은 팝오버에서도 잘리지 않고 연속 입력 후 올바르게 닫힌다.
3. 그룹의 큰 행성은 공개 정보만으로 말하고 작은 행성 카드는 기존 선택 기능을 유지한다. 대사 요청에 원본 로그나 외부 API가 사용되지 않는다.
4. 신규 구매 목록에 인상된 기존 외형과 새 장식이 나타난다. 네 슬롯의 장식이 함께 보이고 각 슬롯에서는 한 상품만 장착된다. 모든 성장 시대와 상점 미리보기에서 그림이 확인된다.
5. 구형 SKU 구매자의 보유·장착과 구매 당시 금액은 유지된다. 같은 외형을 새 가격으로 중복 구매하지 않는다. 미구매자는 새 가격으로만 구매할 수 있다.
6. 비로그인 구매, 로그인 구매, 재시도, 다른 기기의 동시 구매, 첫 로그인 게스트 가져오기, 초기화 후 재장착에서 잔액·보유·장착 상태가 일치한다.
7. 기존 성장 점수·토큰 집계·그룹 공개 범위·순위 계산은 바뀌지 않는다.
