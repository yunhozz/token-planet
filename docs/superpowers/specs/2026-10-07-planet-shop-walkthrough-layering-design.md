# 지형 전체 아바타 이동과 장식 겹침 설계

**상태:** 사용자 지시에 따라 확정 (2026-10-07)

## 목표

아바타 자동 이동 경로를 지면 전체로 확장한다. 상점 장식은 아바타 통행 경로와 겹쳐도 배치할 수 있고, 겹칠 때 아바타가 장식 위에 표시되어 장식 아래를 지나가는 것처럼 보이게 한다.

## 확인한 현재 동작과 문제

- `PlanetLandscape.tsx`의 아바타 이동점은 고정 U자 경로다. 풍경이 넓어져도 지형 전체를 돌아다니지 않는다.
- 상점 배치 검사는 아바타 이동점이 아니라 자연물 자동 배치용 예약 셀을 통행 제한으로 재사용한다. 실제 이동점과 상관없는 지면 좌표도 배치 불가가 된다.
- 저장 단계의 Rust 검사도 통행 예약 셀을 차단한다. TypeScript만 수정하면 미리보기는 허용되고 저장은 거절될 수 있다.
- SVG는 자연물·상점 장식·draft 다음에 아바타를 그리므로 아바타가 장식 위에 표시되는 순서는 이미 맞다. 다만 아바타가 포인터 입력을 가로채면 겹친 장식을 선택하기 어렵다.

## 결정된 동작

1. 아바타 경로는 지형 bounds 전체를 수평 왕복하는 지그재그 경로로 만든다. 각 경로 점의 24×30 아바타 표시 footprint 전체가 지면 안에 있도록 한다.
2. 가로 점 간격은 최대 48, 행 간격은 최대 30으로 제한하고 양쪽 끝과 첫·마지막 행을 포함한다. 각 행을 왕복하고 다음 행 끝에서 되돌아가며, 넓은 지형에서도 표시 영역이 지면을 빠짐없이 훑는다.
3. 경로 진행 방향은 경로 끝에서만 반전한다. 현재의 1–5점 걷기 묶음, 걷기·휴식·눈 깜박임 애니메이션은 재사용한다. 유효한 한 왕복 안에 모든 경로 점을 방문한다.
4. 지형 bounds가 바뀌면 이전 타이머를 취소하고 현재 좌표에서 새 경로의 가장 가까운 유효 점으로 이어간다. 비활성화, reduced motion, unmount 시 기존 정리 동작을 유지한다.
5. 상점 지면 장식은 전체 footprint가 terrain bounds 안이면 배치할 수 있다. 아바타 경로와 겹치는지는 제한하지 않는다. sky 범위와 잘못된 입력·terrain bounds 제한은 유지한다.
6. TypeScript preview와 Rust 저장 판정에서 통행 예약 셀 충돌을 제거한다. 자연물 자동 배치용 `reservedCell`은 유지한다.
7. 아바타를 자연물·상점 장식·preview 뒤가 아니라 앞에 렌더링하고 `pointer-events="none"`으로 겹친 장식에 포인터 입력을 전달한다.

## 수용 기준

1. 경로 생성 함수는 모든 점의 24×30 footprint를 terrain 안에 둔다. terrain 원점·크기가 달라져도 시작·끝과 전체 지면을 포함한다.
2. 인접 경로 점은 같은 행의 수평 이동 또는 같은 가장자리의 수직 연결이다. 순간이동 대각선이 없다. 가로 정지점 간격은 48 이하, 행 간격은 30 이하이다.
3. 경로 진행은 끝점에서만 방향을 바꾸고, 유한한 왕복 동안 각 경로 점을 모두 방문한다.
4. 기존 통행 경로 fixture `(160,140)`, `(1100,200)`, 왼쪽 예약 셀 `(50,200)`, 오른쪽 cosmetic 예약 셀 `(1300,200)`의 지면 장식 배치가 TypeScript 및 Rust에서 모두 허용된다.
5. 전체 장식 footprint가 지면 bounds를 벗어나면 거절한다. sky 규칙과 invalid input의 기존 결과를 유지한다.
6. 경로 위 preview는 유효 상태이고 통행 제한 문구가 없다. 확정 시 해당 좌표의 place 요청을 한 번 전송한다.
7. SVG에서 아바타 그룹은 자연물·장식·draft 뒤에 선언되고 `pointer-events="none"`을 가진다.
8. 기존 걷기·휴식, 방향, reduced motion, 화면 비활성화, 지형 변경, unmount의 타이머 수명 회귀를 유지한다.

## 범위 밖

- 아바타 자산·이동 속도·걷기/휴식/눈 깜박임 스타일 변경
- 자연물 자동 배치의 예약 셀 정책 변경
- 상품 가격, 상점 요청/응답, DB schema 변경
- 지형이나 장식 그래픽 리디자인

## 검증 경계

단위 테스트는 전체 지면 경로와 위치 판정, timer progression, UI 요청·SVG 순서를 확인한다. jsdom은 실제 SVG hit-testing과 애니메이션 장면을 입증하지 못하므로 가능한 경우 desktop에서 여러 지면 위치와 겹친 장식 포인터 선택을 확인한다.
