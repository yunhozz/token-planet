# Token Planet 화면 개선 설계

**작성일:** 2026-09-28

**상태:** 사용자 설계 승인 · 구현 전

## 목표

`행성·그룹 자세히 보기`를 누르면 행성이 첫눈에 보이고, 캐릭터와 장면이 살아 있는 듯 느껴지게 한다. 작은 글씨와 긴 설명을 줄여 기본 화면과 상세 화면 모두 쉽게 읽을 수 있게 한다. 기존 픽셀 행성 스타일, 사용량의 의미, 그룹 공개 범위와 초기화 규칙은 유지한다.

## 화면 구조

### 기본 화면

- 390×700 창에서는 행성을 맨 위에 두고 **현재 시대**, **이번 행성 토큰**, **다음 시대 진행도**를 우선 표시한다.
- `행성·그룹 자세히 보기`는 눈에 띄는 주 동작으로 둔다. 수집 상태와 동기화 오류는 숨기지 않되 정상일 때의 반복 설명은 짧게 표시한다.
- 글자를 키워 내용이 길어지면 화면을 세로로 스크롤한다. 정보를 맞추기 위해 글자 크기를 다시 줄이지 않는다.

### 상세 화면

- 상세 창은 가능한 화면 영역 안에서 약 960×700 크기를 목표로 한다. 좁은 화면에서는 한 열로 배치하고 전체를 스크롤한다.
- 상단에 `내 행성`과 `그룹` 탭을 둔다. 상세 화면을 열 때마다 `내 행성`을 먼저 보여준다. 그룹에 참여하지 않은 경우 `그룹` 탭에서 기존 로그인·그룹 만들기·참여 흐름으로 이어진다.
- `내 행성` 탭의 첫 화면은 약 420px 크기의 행성 디오라마를 중심으로 한다. 캐릭터는 현재보다 크게 보여 걷기와 표정을 알아볼 수 있게 한다. 옆에는 닉네임·현재 시대·이번 행성 토큰·다음 시대 진행도만 우선 배치한다.
- 지갑, 개편 후 누적 토큰, 성장 점수, 다음 오브젝트, 최근 생성물, 개인 전체 사용량, 수집원 설정, 성장 일지와 초기화는 행성 아래의 정보 영역에서 확인한다. 수치와 설정을 삭제하지 않는다. 오류와 `일부 기록 확인 중` 상태는 관련 수치 옆에 바로 표시한다.
- `그룹` 탭에서는 선택한 멤버의 행성을 상단에 크게 보여준다. 다른 멤버는 같은 크기의 작은 행성 목록으로 고르고, 누적 토큰 및 현재 행성 문명 발전 순위표는 아래에 둔다. 선택한 멤버가 없을 때는 첫 멤버의 행성을 보여준다.
- 행성으로 돌아가기, 탭 전환, 그룹 행성 선택은 키보드로도 가능하며 현재 위치와 선택 상태가 분명해야 한다.

## 움직임

- 상세 화면 진입 때 행성이 짧게 나타난다. 평상시에는 행성 전체가 2~3px 범위에서 천천히 떠 있는 효과 하나만 적용한다. 디오라마 자체를 회전시켜 지형이나 캐릭터가 뒤집히게 하지 않는다.
- 캐릭터는 잠시 머문 뒤 **행성 표면의 걸을 수 있는 지점 중 가까운 목적지와 방향을 무작위로 선택**한다. 2~4걸음 걷고 다시 멈추며, 이동 중에는 이동 방향을 바라본다. 행성 경계 밖으로 나가거나 목적지로 순간 이동하지 않는다. 가만히 있을 때는 가끔 눈을 깜빡인다.
- 새 오브젝트가 실제로 추가됐을 때만 짧은 등장 효과를 준다. 값만 다시 조회하거나 탭을 열었다는 이유로 생성 효과를 반복하지 않는다.
- 그룹의 작은 행성 목록은 정지 상태이며 선택해서 크게 보는 행성만 움직인다. 화면 밖에 있거나 창이 보이지 않을 때는 반복 움직임을 멈춘다. 운영체제의 `동작 줄이기` 설정에서는 등장·유휴·걷기 움직임 없이 완성된 정지 장면을 보여준다.
- 움직임은 화면의 장식이다. 성장 점수, 오브젝트 위치, 사용량, 동기화 데이터나 그룹 순위에 영향을 주지 않는다.

## 글자와 시각 체계

- 기존 어두운 밤색 배경과 민트·물색·금색의 픽셀 팔레트를 유지한다. 행성에 가장 강한 명도와 색을 쓰고 주변 패널의 장식은 줄인다.
- 한글 본문에는 시스템 산세리프 글꼴을 사용하고, 브랜드와 숫자에만 현재의 고정폭 느낌을 제한적으로 남긴다. 픽셀 특성은 도형, 테두리, 스프라이트에서 이어간다.
- 기본 본문 16px, 보조 정보 14px, 섹션 제목 20~24px, 핵심 수치 28~32px을 기준으로 한다. 주요 버튼과 입력 요소의 높이는 최소 44px이다. 긴 숫자는 줄바꿈하되 잘라서 다른 값으로 오해하게 만들지 않는다.
- 작은 글씨를 유지하는 예외를 만들지 않는다. 닉네임, 상태, 순위, 성장 일지, 그룹 관리 문구도 같은 글자 단계로 맞춘다.

## 문구 정리

| 위치 | 기본 표시 | 자세한 내용 |
| --- | --- | --- |
| 수집 불완전 | `일부 기록 확인 중` | 수집원 상태에서 미확인 항목 확인 |
| 현재 주기 수치 | `이번 행성 토큰` | 초기화 후 다시 쌓이는 값 |
| 개편 후 수치 | `누적 토큰 (개편 후)` | 순위표 기준과 일치 |
| 과거 포함 수치 | `전체 사용량 (과거 포함)` | 개인 통계에만 표시 |
| 초기화 | `행성 초기화` | 확인창에서 지갑 적립과 자연 생태계로의 복귀를 명시 |
| 그룹 공유 | `그룹에는 행성 모습과 집계값만 공유됩니다` | 공유 정보 펼침 영역에 원본 기록의 비공개 범위를 표시 |

중복 설명과 장식용 소제목은 줄인다. 사용자가 되돌리기 어렵거나 공개 범위를 결정하는 순간에는 필요한 설명을 생략하지 않는다. 오류 문구에는 가능한 다음 동작을 남긴다.

## 구현 경계

- React의 `App.tsx`는 상세 탭과 정보 순서를, `WorldCommunity.tsx`는 선택 행성 중심의 그룹 화면을 담당한다. `PlanetScene.tsx`와 `AvatarSprite.tsx`는 디오라마·캐릭터 표현을 담당한다.
- `App.css`는 크기, 여백, 글자 단계와 움직임을 정의한다. 컴포넌트별 문구는 필요한 위치에서만 수정한다. Tauri의 상세 창 크기 변경은 `src-tauri/src/lib.rs` 범위에 한정한다.
- 서버 API, 성장 공식, 원장, 그룹 순위 계산, 공유 데이터와 초기화 규칙은 변경하지 않는다. 별도의 이미지 생성, 애니메이션 라이브러리, 새로운 사용자 설정은 필요하지 않다.

## 검증 기준

1. 상세 버튼을 누른 직후 행성, 캐릭터, 시대와 이번 행성 토큰이 스크롤 없이 보인다. 그룹 탭으로 한 번에 이동할 수 있다.
2. 390px 기본 창과 상세 창에서 본문·상태·순위·버튼을 읽을 수 있고, 글자 확대나 좁은 화면에서도 정보가 겹치거나 잘리지 않는다.
3. 캐릭터가 여러 번 움직일 때 방향과 목적지가 달라질 수 있으며, 각 이동은 표면 안에서 연속적으로 끝난다. 그룹의 미선택 행성은 움직이지 않는다.
4. `동작 줄이기` 설정과 창 비표시 상태에서 반복 움직임이 멈춘다. 키보드로 탭과 그룹 행성을 선택할 수 있다.
5. 개인 전체 사용량, 개편 후 누적 토큰, 이번 행성 토큰, 성장 점수와 순위의 값과 의미가 변경 전과 같다. 초기화 결과와 그룹 공유 범위를 실행 전에 확인할 수 있다.
